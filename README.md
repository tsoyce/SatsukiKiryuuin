# XSatsu Студия

Один редактор для пригласительных, дипломов, закладок и открыток: шаблон (картинка или **PDF**), таблица
людей, выгрузка **в ZIP по файлу на человека**, общим PDF или листами для печати, **имена файлов по шаблону**.

- Новая версия — папка [`app/`](app/). Карта кода — [`PROJECT_TREE.md`](PROJECT_TREE.md).
- Исходная версия v25 без изменений — [`legacy/v25/`](legacy/v25/).

## Запуск на компьютере

Нужен любой локальный веб-сервер (из `file://` браузер не даст загрузить шрифты):

```
cd app
python3 -m http.server 8000      # или: php -S localhost:8000
```

Откройте http://localhost:8000. Проекты хранятся в браузере (IndexedDB); резервная копия и перенос —
«Проект → Сохранить файл проекта».

## Проверка

```
node tests/core.test.cjs
```

## Размещение на сервере

Сайт статический, PHP и база данных не нужны. Рекомендуемый безопасный вариант — положить Студию **рядом**
со старой версией, ничего не удаляя: содержимое `app/` → `<каталог сайта>/studio/`. Старая версия и её
`invite-data/` продолжат работать, а ссылка «Старая версия» на главной Студии ведёт на `../`.

## Перенос старых проектов

Старые проекты сохраняются в JSON через меню старых редакторов («Проект → Скачать JSON»). На главной Студии
нажмите «Открыть файл проекта…» — поддерживаются пригласительные, дипломы и закладки v25.
