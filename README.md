# XSatsu Студия

Один редактор для пригласительных, дипломов, закладок и открыток: шаблон (картинка или **PDF**), таблица
людей, выгрузка **в ZIP по файлу на человека**, общим PDF или листами для печати, **имена файлов по шаблону**.

- Студия — папка [`app/`](app/), сервер (аккаунты, проекты в MariaDB) — [`server/`](server/). Карта кода — [`PROJECT_TREE.md`](PROJECT_TREE.md).
- Выкладка и обслуживание — [`docs/DEPLOY.md`](docs/DEPLOY.md), интерфейс — [`docs/ui-spec.md`](docs/ui-spec.md).

**Возможности:** векторный PDF-шаблон, поля из Excel (XLSX/ODS/CSV), падежи ФИО (`{ФИО:дат}`), обращение по полу,
QR-коды, «показывать, если», проверка списка перед печатью, ZIP по файлу на запись, листы печати с метками реза,
мастер печати с профилями принтеров, аккаунты, проекты на сервере с версиями, корзиной и совместным доступом, тёмная тема.
- Исходная версия v25 без изменений — [`legacy/v25/`](legacy/v25/).

## Запуск на компьютере

Нужен любой локальный веб-сервер (из `file://` браузер не даст загрузить шрифты):

```
cd app
python3 -m http.server 8000      # или: php -S localhost:8000
```

Откройте http://localhost:8000. Без сервера проекты хранятся в браузере (IndexedDB); резервная копия и перенос —
«Проект → Сохранить файл проекта». С сервером и базой — см. «Локальная разработка» в `docs/DEPLOY.md`.

## Проверка

```
node tests/core.test.cjs     # ядро
node tests/api.test.cjs      # сервер (нужна MariaDB/MySQL, см. начало файла)
```

Обе проверки идут в GitHub Actions на каждый PR.

## Размещение на сервере

Одна команда — `tools/deploy/server-install.sh` (база, конфигурация, миграции, обновление сайта). Подробно — `docs/DEPLOY.md`.
Можно и без сервера: скопировать содержимое `app/` в корень сайта — Студия будет работать с проектами в браузере.

## Перенос старых проектов

Старые проекты сохраняются в JSON через меню старых редакторов («Проект → Скачать JSON»). На главной Студии
нажмите «Открыть файл проекта…» — поддерживаются пригласительные, дипломы и закладки v25.
