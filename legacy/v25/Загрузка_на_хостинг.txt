ЗАГРУЗКА И ОБНОВЛЕНИЕ РЕДАКТОРА v19

УСТАНОВКА И ОБНОВЛЕНИЕ
1. Нужен PHP 7.4+ (лучше актуальный 8.x), без базы данных и Node.js.
2. Перед обновлением скопируйте всю invite-data и свой config.php
   в резервную копию. Эти папку и файл не удаляйте при обновлении.
3. Загрузите содержимое priglasitelnye в папку сайта. Замените HTML,
   CSS, api.php и все JS, включая bookmark-font-codec.js, шрифты и vendor. Файлы должны
   оставаться рядом. PHP должен создавать invite-data и писать в неё.
4. Откройте index.html через HTTPS и нажмите Ctrl+F5. Прежние проекты,
   коды и история сохраняются. Старые проекты без указания размера
   открываются как А6; новые создаются в А5 с более крупным текстом.

ВХОД И СОХРАНЕНИЕ
При запуске открывается общий каталог. Закладки можно открыть сразу.
Для серверных пригласительных укажите имя / login, покажите список
и выберите проект. Сам редактор пригласительных — invitations.html.
Для защищённого проекта нужен код, для открытого — только имя.
Имя — подпись, которую вводит пользователь, без регистрации и проверки
личности. Проект без кода может открыть и изменить любой посетитель,
указав имя. «Новый» и «Проект» → «Создать копию» создают отдельные записи.
Дальше правки сохраняются автоматически; «На хостинге ✓» подтверждает
сохранение. В другом браузере защищённый проект снова попросит код.

ФОРМАТ И ПЕЧАТЬ
Размер меняется на вкладке «Макет» или через «Изменить» над просмотром.
Доступны А6, А5, А4, конверт 210 × 99 мм, вытянутый 210 × 74 мм,
свой размер 50–420 мм и обе ориентации. При включённом изменении кегля
текст масштабируется вместе с форматом. Для других пропорций можно
выбрать чистый фон, рамку либо загрузить свой макет.

«Печатать…» открывает настройки, затем обычное окно печати устройства.
Скачивать и открывать PDF перед этим не нужно. Выберите гостей/бланки,
слой, бумагу и размещение. По умолчанию размер настоящий, без скрытого
уменьшения. Поля могут уменьшить число карточек на листе. Например,
без полей на А4 помещаются 4 А6 или 2 А5; с полями 5 мм — 2 А6 или 1 А5.
«Уместить с уменьшением» включается только явно. В драйвере оставьте
ту же бумагу, ориентацию и масштаб 100%; не задавайте повторную раскладку.

Для печати в два прохода сначала «Только фон» — на струйнике или
лазернике, затем «Только текст и поля» — на лазернике. Между проходами
не меняйте бумагу, поля, размещение, список гостей и направление подачи.
Сначала проверьте один лист. Надписи внутри загруженной картинки входят
в фон: для чистой основы нужна картинка без этих надписей.

Фольгирование находится только в «Дополнительно…» →
«Тонерное фольгирование».
Для тонерной фольги основу печатайте струйным способом, маску —
лазерным: фольга реагирует и на остальной открытый тонер.

ИСТОРИЯ И РЕЗЕРВНЫЕ КОПИИ
«Проект» → «История действий» показывает входы, сохранения, доступ,
импорт, экспорт и
открытие диалога печати. Запись печати не подтверждает физический выход
бумаги: пользователь может отменить печать в системном окне.
Сервер хранит последние 1000 событий проекта. Для сохранения журналов
и доступа нужна вся invite-data. «Скачать проект» сохраняет JSON
с гостями, макетом, блоками, форматом и шрифтами.

Один файл Пригласительная.html работает локально без установки программ:
укажите имя и продолжайте в браузере. Серверная память, каталог проектов
и серверный журнал доступны при загрузке всей папки на PHP-хостинг.
