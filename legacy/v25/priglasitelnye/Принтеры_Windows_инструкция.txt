ДАННЫЕ ПРИНТЕРОВ ИЗ WINDOWS

Обычная кнопка «Печатать» открывает системное окно: принтер выбирается там.
Для неё не нужны профили и помощник Windows.

В мастере можно заполнить названия из списка установленных в Windows очередей:
1. На компьютере, с которого будете печатать, скачайте Read-Printers-Windows.ps1.
2. Откройте файл через PowerShell. Помощник запишет Printers-Windows.json
   на рабочий стол. Он читает список и настройки по умолчанию, не меняя
   принтеры, драйверы, задания и параметры. Пробная страница не печатается.
3. В мастере выберите импорт данных Windows и откройте этот JSON.
4. Выберите нужную очередь для профиля. Название заполняется из файла.
   При наличии данных можно посмотреть драйвер, бумагу, цвет и дуплекс
   по умолчанию на момент экспорта.

Если Windows запрещает запуск скачанного PS1, менять политику выполнения
не нужно. Используйте «Скопировать команду», откройте обычный PowerShell,
просмотрите и вставьте команду. Она выполняет тот же читаемый помощник
и сохраняет JSON на рабочем столе. Также можно продолжать с ручным профилем.

JSON обрабатывается локально, на сервер не загружается. Помощник не выгружает
пароли и отдельные поля адресов портов или имени компьютера. Название сетевой
очереди может само содержать имя сервера или адрес, как в Windows. Файл также
содержит названия драйверов и полученные настройки по умолчанию. После смены
компьютера или драйвера получите новый файл.

Настройки драйвера — это не список всех возможностей устройства и не
подтверждение фактической подачи. Импорт не определяет сторону бумаги,
верхний край, порядок стопки и поправку совмещения. Для них остаются
пробы на одном и двух листах. Вновь импортированный профиль всегда
начинает с неизвестной подачи, без переноса прежней калибровки по имени.

Браузер не получает выбранное в системном окне имя принтера и не может
самостоятельно изменить его настройки. Выберите нужный принтер в этом окне.
Помощник Windows не нужен хостингу, не требует Node.js, расширения браузера
или локального сервиса. Его запускают только на своём Windows-компьютере.

Повторный запуск обновляет существующий JSON этого помощника.
Посторонний файл с тем же именем не перезаписывается.
