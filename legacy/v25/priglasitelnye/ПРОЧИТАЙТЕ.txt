НАЧАЛО РАБОТЫ
На хостинге откройте index.html. В карточке «Продолжим?» укажите
«Ваше имя / login» и нажмите «Показать проекты». Выберите проект:
для защищённого введите код, для проекта без кода нажмите «Открыть проект».
Доступны поиск по названиям, «Новый проект» и «Продолжить в браузере».
На телефоне есть переходы «Гости», «Текст и макет», «Печать».
Имя обязательно при каждом новом посещении; браузер может подставить
предыдущее значение. Это подпись в истории действий, а не регистрация
и не проверенная учётная запись. Имя вводит сам пользователь.

«Все проекты» возвращает к выбору. Верхний список «Проект» позволяет
быстро переключаться между проектами на этом хостинге. Для смены имени
нажмите кнопку со своим именем в верхней панели. Каталог показывает
названия серверных проектов; коды, гости и содержимое в список не входят.
Сохранённый ранее код не открывает защищённый проект автоматически
при новом посещении — его нужно ввести в карточке входа.

НОВЫЙ ПРОЕКТ, КОПИЯ И ДОСТУП
«Новый» над редактором (или «Новый проект» в начальной карточке) — макет А5, три текстовых блока, пустой список гостей.
Обычный кегль — 14 пт, для отдельного оформления имени — 18 пт.
Прежние проекты сохраняют свой формат: проекты без указанного размера
открываются как А6. Их можно увеличить на вкладке «Макет». «Проект» → «Создать копию» — отдельный проект со всеми текущими гостями,
макетом, блоками и шрифтами. Задайте название. Для ограничения входа
включите «Защитить проект кодом» и придумайте код; можно просто 1.
Без этой отметки проект создаётся без кода.
Проект без кода может открыть и изменить любой посетитель сайта,
указав своё имя. Для защищённого проекта нужны имя и код.
Код чувствителен к регистру: 1–128 символов, пробелы по краям удаляются.
Занятый код нельзя использовать для другого проекта.

В окне «На хостинге» код можно изменить, установить или отключить.
После смены прежний код перестаёт работать, запись проекта в списке
остаётся той же. Если код изменили на другом устройстве, откройте проект
заново с новым кодом. Храните код отдельно от браузера.

АВТОСОХРАНЕНИЕ И СОВМЕСТНАЯ РАБОТА
Текст, гости, блоки, оформление, координаты, макет и шрифты сохраняются
автоматически. В подключённом проекте — на хостинге, при локальной
работе — в этом браузере. «На хостинге ✓» подтверждает серверное сохранение.
Перед переходом в другой проект редактор сохраняет текущие правки.
Если сохранение не удалось, переход останавливается.

При потере связи остаётся локальный черновик. Дождитесь подтверждения
сохранения либо скачайте JSON через «Скачать проект» перед закрытием.
В окне «На хостинге» есть «Проверить подключение» и «Сохранить сейчас».
У разных серверных проектов отдельные черновики. Если другой редактор
уже сохранил новую версию, ваша устаревшая версия её не перезапишет.
Можно открыть серверную версию или сохранить свои правки отдельной копией.
Автоматического объединения разных версий нет.

ИСТОРИЯ ДЕЙСТВИЙ
«Проект» → «История действий» показывает время, введённое имя / login
и действие.
На хостинге записываются вход, открытие и создание проектов, сохранение
изменений, смена доступа, импорт, экспорт и открытие диалога печати. Изменения группируются
по сохранениям: журнал не является записью каждого нажатия клавиши.
Сервер хранит последние 1000 записей журнала проекта. Локальная история
остаётся в браузере. Действия из версий без журнала не восстанавливаются
задним числом.
В журнале печати отмечается открытие окна печати, а не подтверждённый
выход бумаги из принтера. Отмена в окне устройства может быть не видна
редактору. История действий и отмена изменений — разные функции.

ГОСТИ И ВСТАВКА СПИСКА
«Импорт» → вставьте список через Ctrl+V, по одному ФИО в строке.
Можно вставить нумерованный список, ячейки Excel или загрузить
CSV / TSV / TXT / JSON. XLSX напрямую не импортируется: скопируйте

Заголовки CSV: ФИО;Пол;Email. Разделители — ; , или табуляция.
Без заголовков: ФИО, пол, email; также распознаются отдельные столбцы

ФИО выводится как введено, без автоматического склонения.
Экспорт списка — CSV для Excel или JSON.

В карточке гостя можно выбрать «Автоматически по ФИО» либо вручную

ТЕКСТ И ОТДЕЛЬНОЕ ОФОРМЛЕНИЕ ФИО
Каждый текстовый блок имеет свои шрифт, кегль, начертание, цвет, градиент,
интервалы, выравнивание и положение. Блоки можно добавлять, дублировать,
удалять и менять местами; максимум 30. Старый единый текст открывается
одним блоком. Выберите блок в списке или по рамке на открытке.
Переменные: {ФИО}, {обращение}, {мероприятие}, {email}.
Мужское, женское и нейтральное обращения настраиваются отдельно.
Переносы и знаки препинания добавляйте в шаблон текста.

Чтобы имя отличалось от остального текста, откройте «Отдельное оформление
ФИО» и включите «Выделять имя отдельно». Настройте шрифт имени, кегль,
цвет / градиент, жирность, курсив, подчёркивание, межбуквенный интервал
или подложку. Есть варианты оформления для быстрой настройки.
Эти параметры применяются к {ФИО}; остальной текст использует обычные
настройки выбранного блока. Например, основной текст — Gogol, имя —
Georgia или PT Serif. Для связного рукописного шрифта начните с нулевого
межбуквенного интервала.
Кегль указан в пунктах. Автоподбор уменьшает текст для длинных имён.
«Проверить всех гостей» помогает найти переполнение до экспорта.
Если текст не помещается, увеличьте рамку или уменьшите кегль.

ШРИФТЫ И БИБЛИОТЕКИ
«Библиотеки» → выберите Google Fonts или Fontsource → «Добавить».
Google Fonts: 16 предложенных семейств; другое семейство можно искать
по точному имени. Fontsource: 12 семейств с кириллицей — PT Sans,
PT Serif, Fira Sans, IBM Plex Sans, IBM Plex Serif, Manrope, Philosopher,
Bad Script, Lobster, Neucha, Amatic SC, Ubuntu.
Первое скачивание требует интернета. Fontsource загружается через
jsDelivr. Файлы кириллицы и латиницы сохраняются в проекте и затем
восстанавливаются вместе с ним без повторной загрузки из библиотеки.

TTF / OTF / WOFF / WOFF2, включая свой Gogol, добавляются через
«Загрузить файл». После загрузки шрифт доступен и блоку, и оформлению ФИО.
Удаление — «Управление загруженными шрифтами».
Ссылки на Паратайп и Font Squirrel открывают внешние каталоги; скачанный
файл добавляется обычной загрузкой. Условия использования и поддержка
кириллицы зависят от выбранного шрифта и указываются у его автора.

ФОРМАТ И ЧИТАЕМОСТЬ
Размер меняется на вкладке «Макет» или кнопкой «Изменить» рядом с
размером над предпросмотром. Доступны:
А6 — 105 × 148 мм;
А5 — 148 × 210 мм;
А4 — 210 × 297 мм;
«Конверт» — 210 × 99 мм;
«Вытянутый» — 210 × 74 мм;
«Свой размер» — ширина и высота от 50 до 420 мм.
Ориентация карточки задаётся отдельно: вертикальная или горизонтальная.
Размер карточки и размер бумаги для печати — разные настройки.

«Изменять кегль вместе с форматом» увеличивает или уменьшает кегль
при смене физического размера. Например, переход с А6 на А5 позволяет
сделать текст крупнее, сохранив относительное расположение блоков.
Если отметку убрать, кегль останется в заданных пунктах.
После изменения проверьте все блоки и длинные ФИО. Автоподбор может
уменьшать текст, если он не помещается. Для читаемости увеличьте рамку,
сократите текст или используйте больший формат.

ФОН И РАЗМЕЩЕНИЕ
На вкладке «Макет» выберите «Исходный макет», «Чистый фон» или «Рамка».
Готовый фон «День социолога» — вертикальная картинка. Для вытянутой
карточки или другой ориентации удобнее чистый фон, рамка либо свой
PNG / JPG / WebP. Режимы размещения загруженного фона: на всю карточку,
уместить целиком, заполнить с обрезкой. Если пропорции не совпадают,
проверьте, не растянут ли рисунок и не перекрывает ли его текст.

На вкладке «Размещение»: сетка, линейки, привязка, шаг 1–20 мм.
Координаты и размеры задаются в миллиметрах от верхнего левого угла
выбранного формата. Блок можно перетаскивать и растягивать.
Стрелки — шаг сетки, без привязки — 1 мм; Shift + стрелки — 10 мм,
Alt + стрелки — 0,1 мм. Есть выравнивание относительно всей карточки.
Сетка, линейки и рамки редактора в готовые файлы не попадают.

ПЕЧАТЬ ИЗ БРАУЗЕРА
Нажмите «Печатать…» под предпросмотром или в разделе «Печать и файлы».
Скачивание PDF для этого не требуется. В окне редактора выберите:
кого печатать — всех гостей, выбранного гостя или бланки под ручку;
слой — «Фон и текст», «Только фон» или «Только текст и поля»;
бумагу — А4, А5 или «По размеру приглашения»;
размещение — несколько карточек на листе или одно на листе.
«Линии разреза» можно включить или отключить.

В «Поля, ориентация и масштаб» доступны поля 0 / 5 / 10 мм,
ориентация бумаги и «Уместить с уменьшением». По умолчанию уменьшение
выключено: карточки печатаются в указанном физическом размере.
Если макет не помещается, редактор попросит изменить параметры.
Количество на листе рассчитывается по размеру и полям, а не всегда
равно четырём. Например, без полей на А4 помещаются четыре А6 или
два А5; с полями 5 мм — два А6 либо один А5. А4 с положительными
полями не помещается на бумаге А4 в полном размере.

«Уместить с уменьшением» включайте только когда уменьшение допустимо.
Оно явно меняет физический размер напечатанной карточки. Параметры
и количество на листе видны в окне печати до отправки на принтер.

Затем нажмите «Печатать»: откроется обычное окно печати компьютера
или телефона. Выберите принтер, ту же бумагу и ориентацию; масштаб —
100% / «Фактический размер». Не добавляйте повторно уменьшение,
поля или «несколько страниц на листе» в драйвере, если это уже сделано
редактором. Печать без полей требует соответствующего режима принтера.
Если он недоступен, выберите поля и подходящее размещение или явно
разрешите уменьшение. Для большого своего формата нужны подходящие
бумага и принтер. Сначала проверьте один лист.

ПОСЛОЙНАЯ ПЕЧАТЬ В ДВА ПРОХОДА
1. В «Печатать…» выберите гостей или бланки, бумагу, поля и размещение.
2. Слой «Только фон» — напечатайте на струйном или лазерном принтере.
3. Загрузите эти же листы повторно. Слой «Только текст и поля» —
   напечатайте текст, ФИО и поля бланка на лазерном принтере.
4. В обоих проходах оставьте одинаковые размер, бумагу, ориентацию,
   поля, масштаб, порядок гостей и направление подачи листа.

Геометрия слоёв совпадает. Между проходами не меняйте макет или список
гостей. Прогоните один пробный лист для проверки совмещения и того,
какой стороной принтер принимает бумагу.
Текст, который уже находится внутри загруженной картинки, является
частью фона: автоматически отделить его редактор не может. Для фона
без надписей загрузите исходную картинку без текста.

ГОСТЕВЫЕ БЛАНКИ ПОД РУЧКУ
Откройте «Бланки для заполнения от руки» в разделе «Печать и файлы».
Задайте количество 1–200, обращение и отметку «Линия для ФИО».
На месте {ФИО} будет линия, на которой можно вписать имя после печати.
Переменная {ФИО} должна оставаться в нужном текстовом блоке.
«Посмотреть бланк» показывает его, не заменяя список гостей.
«Печатать бланки…» открывает печать из браузера. Также доступны
«Скачать бланки PDF» и «Скачать один бланк PNG».
Бланки используют текущий формат карточки и настройки бумаги.
Последний лист может быть заполнен частично.

СКАЧИВАНИЕ ФАЙЛОВ
«Скачать эту открытку» — отдельное изображение; «Все открытки в ZIP» —
изображения по гостям. Формат JPG / PNG и качество доступны в
«Параметры скачивания и PDF». Там же — «Скачать PDF для печати».
Имя файла: Название мероприятия _ Пригласительный _ ФИО.jpg / .png.
Недопустимые символы заменяются, совпавшие имена получают суффикс.
Прикрепите изображения к письмам самостоятельно.
PDF использует ту же геометрию бумаги, размещения и масштаба, что
печать из браузера. Количество карточек на листе зависит от размера.
Выбранный в окне печати слой также используется при создании PDF.

ДОПОЛНИТЕЛЬНЫЕ НАСТРОЙКИ И ФОЛЬГИРОВАНИЕ
Фольгирование убрано из основных действий. Нажмите «Дополнительно…»
в разделе «Печать и файлы», затем откройте «Тонерное фольгирование». Там можно отметить
текстовые блоки для фольги, выбрать чёрную маску 600 или 300 dpi,
метки совмещения и скачать комплект для гостей либо бланков.
Предпросмотр специальных слоёв также находится в этом меню.

Комплект содержит основу без отмеченных блоков, чёрную маску,
контроль полного вида и «Порядок_печати.txt». Маска — 1 бит,
без полутонов и JPEG; цвет и градиент заменяются сплошным чёрным.
Подложка имени в чёрную маску не входит. У всех слоёв одинаковые
размер бумаги, позиции и масштаб. При полях от 5 мм можно включить
метки совмещения вне карточек.

Для тонерной фольги основу печатайте струйным способом либо изолируйте
остальной тонер: фольга реагирует на весь открытый тонер. Маску —
лазерным принтером, чёрно-белый режим, без экономии тонера. Оба прохода
должны иметь одинаковые параметры и подачу. Бумага, фольга и режим
ламинатора подбираются под оборудование. Сначала проверьте один лист.

ОТМЕНА И ПОВТОР
Стрелки над редактором отменяют и возвращают текст, гостей, блоки,
размещение, оформление, шаблон и шрифты. Вне полей ввода: Ctrl+Z —
отмена, Ctrl+Shift+Z / Ctrl+Y — повтор. В текстовом поле действуют обычные
сочетания браузера. Быстрый набор объединяется в один шаг; выбор гостя
или блока отдельным шагом не считается. Отменённые правки сохраняются
автоматически. После открытия другого проекта история отмены начинается
заново; она относится к текущему сеансу и в JSON не входит.

РЕЗЕРВНЫЕ КОПИИ, ХОСТИНГ И ОБНОВЛЕНИЕ
«Скачать проект» сохраняет JSON с гостями, блоками, фоном и шрифтами;
«Проект» → «Открыть из файла» восстанавливает его. Файл JSON — резервная копия
содержимого. Серверные коды и журналы хранятся на хостинге; для их
резервирования копируйте всю папку invite-data.
Для хостинга нужны PHP 7.4+ (предпочтительно актуальный 8.x) и права
PHP на создание / запись invite-data рядом с api.php. База данных,
Node.js и установка зависимостей не нужны. Обычно config.php не требуется;
пример необязательных настроек — config.example.php.

SAFARI И АДРЕС САЙТА
В v7 исправлена политика запросов, из-за которой браузер мог передать
пустой источник и получить ошибку «Запрос с другого сайта отклонён».
Для этого обязательно обновите cloud.js вместе с api.php и остальными
файлами. Проверка чужих сайтов не отключается.
Открывайте редактор по одному адресу, например https://o.utmns.ru.
Если HTTPS завершается на прокси и PHP видит HTTP, при необходимости
укажите внешний адрес без пути в своём config.php:
'public_origin' => 'https://o.utmns.ru',
Особенно это важно для старых браузеров без Fetch Metadata.
Произвольным X-Forwarded-* запросам редактор не доверяет.
По умолчанию: 32 МиБ на проект, 100 проектов, 512 МиБ суммарно,
до 10 новых проектов в час с одного IP.

Перед обновлением сделайте резервную копию invite-data и config.php.
Замените все файлы редактора, включая api.php, HTML, CSS и JS;
invite-data и свой config.php сохраните. Обновите страницу через Ctrl+F5.
Старые проекты появятся в каталоге автоматически, прежние коды сохранятся.
Смена кода сохраняет тот же проект и его историю.
Для локальной работы откройте Пригласительная.html или index.html двойным
щелчком, укажите имя и выберите работу в браузере. Серверный каталог
и серверная история требуют размещения всей папки на PHP-хостинге.
Очистка памяти браузера может удалить локальные черновики; сохраняйте
важные проекты также в JSON.
