Управление

Стрелки перемещают блок; на угловом маркере — меняют размер. Alt + стрелка: шаг 0,1 мм. Точные размеры — в «Размещении». Чтобы передвинуть холст, зажмите пробел и перетащите его.

Обращения для мужчин и женщин

Поставьте в тексте {обращение}. Знаки препинания добавьте в сам текст.

Отдельное оформление ФИО

Применяется к переменной {ФИО}. Остальной текст сохраняет оформление блока.

Перетаскивание и размер привязываются к шагу сетки. Стрелки — шаг сетки, Shift — 10 мм, Alt — 0,1 мм.

Размер выбирается выше. После смены формата проверьте текст в предпросмотре.

Импорт гостей

Вставьте ФИО по одному на строку — пол определится автоматически. Также поддерживаются CSV / JSON и ячейки Excel.

Пол определяется по ФИО: отчеству, имени и фамилии. Неоднозначные случаи отмечаются для проверки. Ручной выбор всегда можно изменить.

Результат проверки

Загруженные шрифты

TTF, OTF, WOFF и WOFF2. Шрифты сохраняются вместе с проектом.

Библиотеки шрифтов

Шрифты загружаются в проект и остаются в нём для дальнейшей работы. Свой Gogol и другие файлы можно добавить через «Загрузить файл».

Другие каталоги: Паратайп · Font Squirrel. Скачанный файл добавляется через загрузку; условия использования указаны у автора шрифта.

Проект на хостинге

Гости, макет, текст и шрифты сохраняются вместе. Выберите проект в «Продолжим?». Код нужен только для защищённых проектов; имя / login обязательно.

Дополнительные настройки

Тонерное фольгирование

Отметьте блоки для фольги. Скачиваются основа, чёрная маска и контроль совмещения.

Для тонерной фольги основу печатают струйным способом, чёрную маску — лазерным. Остальной открытый тонер тоже притягивает фольгу.
