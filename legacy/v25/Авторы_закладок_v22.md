## Как применяются исправления

После обновления приложения перезагрузите вкладку и откройте сохранённый проект закладок. Известные подписи исправятся и сохранятся автоматически в том же проекте. Изображения не перезаписываются. При ошибке сохранения старые данные остаются целыми; можно повторить открытие. Исходный вариант хранится в поле карточки `sourceName` и включается в JSON-экспорт.

Справочник общий для начального набора, Word, JSON и сохранённых проектов. Сопоставляются только перечисленные варианты с учётом регистра, пробелов, точек и знаков ударения. Неизвестное имя не заменяется по похожей фамилии. Например, Гёте и Бронислав Малиновский не подменяются Гегелем или Богдановым.

## Файлы

- `bookmark-authors.json` — читаемый справочник с именами, вариантами и ссылками.
- `bookmark-authors.js` — его браузерная копия, встроенная также в автономные HTML. JSON и JS обновляются вместе; изменение одного JSON на хостинге само по себе не обновляет встроенную копию.
- `bookmark-seed.js` — 35 карточек с едиными подписями и сохранёнными исходными вариантами.

Сборка для разработчика: `work/build-bookmark-authors.cjs` читает JSON и пересоздаёт браузерный модуль; `work/normalize-bookmark-seed.cjs` обновляет только подписи существующего набора и проверяет неизменность цитат/изображений. Хостингу и пользователю установка Node.js не нужна.

При загрузке v22 обновите все файлы приложения, сохранив `invite-data` и свой `config.php`. Для автономного режима замените «Проекты.html» и «Закладки.html», сохранив их рядом с «Пригласительная.html».
