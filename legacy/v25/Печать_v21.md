# Печать в v21

В обоих редакторах доступны две отдельные команды.

| Команда | Когда использовать |
| --- | --- |
| **Печатать** | Подготовить текущие страницы и сразу открыть системное окно выбора принтера. |
| **Мастер печати** | Выбрать диапазон, повторить весь набор листов, разделить цвет и текст между принтерами, пройти подачу и последовательность проходов. |

## Обычная печать

1. В закладках выберите стороны и слой макета. В приглашениях параметры бумаги и источника доступны через **«Параметры обычной печати…»** в разделе скачивания.
2. Нажмите **«Печатать»**. После подготовки страниц откроется системное окно; мастер не открывается.
3. В системном окне выберите принтер, ту же бумагу, масштаб **100%**, одну страницу документа на листе. При печати чередующихся лиц и оборотов включите автоматический дуплекс с выбранным в редакторе краем.

Обычный путь не использует сохранённые в мастере повторы, рецепт двух принтеров или поправки профиля. Экземпляры отдельных карточек закладок уже учтены. Дополнительные копии обычного задания можно выбрать в системном окне.

**«Скачать PDF»** закладок также работает напрямую. Команды пробного листа готовят только текущий исходный лист. PDF приглашений использует тот же выбранный источник — всех гостей, одного гостя или бланки — и сохранённое качество.

За один прямой запуск подготавливаются до 100 страниц. Для большего задания используйте мастер: он делит его на пакеты.

## Мастер печати

1. Нажмите **«Мастер печати»**. На узком экране верхняя кнопка называется **«Мастер»**.
2. Выберите листы, стороны и **«Повторить набор листов»**. Например, 35 закладок занимают шесть листов; три набора — 18 физических листов. Неполный последний лист повторяется целиком.
3. Выберите один принтер, ручной переворот, автоматический дуплекс либо два принтера.
4. При необходимости выберите профили подачи. Нажмите **«Подготовить тираж»**.
5. Для каждого прохода следуйте схеме загрузки и порядку листов, затем нажмите **«Печатать проход…»**.
6. После реального отпечатка нажмите **«Проход напечатан · дальше»**. Отмена системного окна сама не завершает проход; его можно повторить.

В двухпринтерном режиме с обеими сторонами последовательность такая: струйный — лицо, струйный — оборот, лазерный — лицо, лазерный — оборот. Для каждого из этих проходов в системном окне отключите дуплекс и оставьте **один экземпляр**: весь тираж уже включён в подготовленные страницы. Дайте чернилам высохнуть перед повторной подачей.

Мастер фиксирует данные и порядок на задание. Для смены количества или диапазона выберите **«Изменить тираж»**. Для правки текста/макета закройте мастер, измените проект и подготовьте задание заново.

## Сведения о принтерах Windows

Обычная печать использует список принтеров самого системного окна. Приложению не нужно заранее знать имя выбранного устройства.

Чтобы заполнить профиль мастера:

1. Раскройте **«Импорт принтеров из Windows»**.
2. На том Windows-компьютере, с которого печатаете, выполните читаемую команду через **«Скопировать команду»** либо используйте **«Скачать помощник .ps1»**. При желании сначала раскройте текст команды. Установка, Node.js и локальная служба не требуются.
3. Команда создаст на рабочем столе `Printers-Windows.json`. Выберите **«Открыть файл принтеров…»** и загрузите его в мастер.
4. Выберите очередь и назначение — обычный, струйный или лазерный принтер. Нажмите **«Добавить в профили»**. Название будет заполнено из Windows.

Помощник читает установленные очереди и сообщённые драйверами текущие настройки: бумагу, цвет и дуплекс. Он не печатает пробу и не изменяет конфигурацию. Недоступные сведения остаются неизвестными. JSON обрабатывается на устройстве и не отправляется на хостинг. Файл может содержать сетевой адрес внутри имени очереди; создавайте новый отчёт после смены компьютера или драйвера.

Параметры драйвера — **настройки по умолчанию**, а не подтверждённые возможности устройства. Импорт не определяет сторону/край подачи, порядок стопки или сдвиг. Новый профиль начинает с неизвестной подачи; старый проверенный профиль с таким же именем не заменяется. Для конкретного принтера и лотка остаются пробы на одном и двух листах.

Если Windows блокирует скачанный `.ps1`, можно просмотреть и вставить ту же команду в обычный PowerShell; менять политику выполнения не требуется. Ручное создание профиля остаётся доступным.

## Совмещение сторон

Ориентируйтесь на вертикальный А4 210 × 297 мм, даже если закладки читаются горизонтально. При перевороте вокруг длинного края пять заполненных ячеек выглядят так:

```text
Лицо             Оборот
1  2  3          3  2  1
4  5  ·          ·  5  4
```

После физического переворота пустые области совпадут. В мастере используйте один ориентир **«ВЕРХ ЛИЦА»** для всех принтеров. Перед большим тиражом выполните все проходы на одном листе и проверьте его на просвет. Контрольная линия пробы должна иметь длину 50 мм. Масштаб и неправильную сторону сначала исправляйте в настройках/подаче; поправка X/Y исправляет только равномерный сдвиг.

## Обновление

Загрузите все файлы `priglasitelnye` из архива v21, сохранив `invite-data` и свой `config.php`, затем перезагрузите вкладку. Для автономного режима положите рядом `Проекты.html`, `Пригласительная.html` и `Закладки.html`. Профили и отчёты устройств хранятся локально.
