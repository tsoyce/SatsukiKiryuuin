# Обновление v25 · дипломы А4

Добавлен самостоятельный раздел **«Дипломы»** с входом с главной страницы и из верхнего меню. Можно готовить награды командам и отдельным людям: редактировать получателя, основание, заголовок и сведения о событии; выбирать I, II, III место, награждение без места или строку для ручного заполнения.

Ручное заполнение имени и основания включается независимо. Флажки скрывают печатный текст, сохраняя введённые значения в проекте. Дата, город, событие, дополнительная строка и логотипы отключаются отдельно. Предусмотрены одна или две обязательные линии подписи: руководитель кафедры, оргкомитет либо оба. Должности редактируются, печатные имена подписантов необязательны.

Один диплом занимает один лист А4. Доступны тираж для каждого получателя, вывод всего списка, выбранного диплома и бланков. **«Печатать»** открывает системное окно напрямую, **«Скачать PDF»** готовит файл, а **«Мастер печати»** организует диапазоны, повторы, проходы и совмещение. Вывод разделяется на всё оформление вместе, струйный слой оформления и лазерный слой текста и линий.

Базовые оформления — **«Классический»** и **«Первый иней»**. Шаблон Дня социолога вынесен в необязательный `diploma-preset-sociology.js`; его удаление не отключает редактор и не меняет сохранённые проекты. Общие файлы фона и логотипов для «Первого инея» от этого шаблона не зависят.

Дипломы сохраняются локально в IndexedDB браузера. Для резервной копии и переноса на другое устройство используются команды JSON в меню **«Проект»**. Серверное или облачное сохранение дипломов не добавлено. Существующие проекты приглашений и закладок используют прежние хранилища; новое хранилище дипломов их не переписывает.

## Размещение обновления

Папка `priglasitelnye` предназначена для статического размещения либо существующего PHP-хостинга. Для серверных функций приглашений по-прежнему нужен PHP; новому разделу дипломов серверная база данных не нужна. Node.js для работы сайта и хостинга не требуется.

Загрузите файлы приложения из архива обновления, сохранив существующие `invite-data` и свой `config.php`. Эти пользовательские данные и конфигурация **не включаются в архив обновления** и не должны заменяться при развёртывании. Обновите HTML, скрипты и стили вместе, затем перезагрузите вкладку. Для автономного комплекта используйте пересобранные HTML-файлы, включая `Дипломы.html`.

Подробные действия — в `Дипломы_инструкция_v25.md`. Этот файл описывает состав и применение обновления; итоговые результаты проверки сборки оформляются отдельно.
