# Дерево проекта XSatsu

> Карта «где что лежит и за что отвечает». **Обновляйте этот файл в каждом изменении структуры** —
> новый файл, перенос функции, новый режим. Если описание и код расходятся — прав код, исправьте описание.

## Идея: одно ядро — много продуктов

Пригласительные, дипломы, закладки и открытки — это **один и тот же документ**:

```
Документ (xsatsu-doc)
├── page            размер макета, мм
├── sides[]         стороны: лицевая, оборот…
│   ├── background  фон: картинка ИЛИ страница PDF (остаётся вектором в выгрузке)
│   ├── elements[]  текст · изображение · фигура · линия · контур (координаты в мм); el.group — id группы
│   └── groups[]    группы слоёв {id, name, collapsed}; элементы группы всегда идут подряд (Model.cleanGroups)
├── data            таблица записей: столбцы (= поля {ФИО}, {Место}…) и строки (= люди / команды / цитаты)
├── greeting        правило для поля {Обращение} (Уважаемый / Уважаемая по полу)
├── assets          файлы проекта (картинки, PDF) в data:URL
├── fonts           загруженные шрифты (TTF/OTF)
└── output          настройки выгрузки: упаковка, формат, раскладка, шаблон имени файла
```

`kind` (Пригласительные / Дипломы / Закладки / Открытки / Свой) — только подпись и имя файла по умолчанию.
Любой шаблон умеет всё: PDF-фон, ZIP, листы печати, оборот, поля, линии для заполнения от руки.

Конвейер одинаковый для всех:
`документ + запись + сторона → XS.Scene.build() → список операций (мм) → экран/PNG (render-canvas) или векторный PDF (render-pdf)`.

## `app/` — Студия

```
app/
├── index.html              одна страница: главная (#/), редактор (#/doc/<id>), диалоги; порядок подключения скриптов
├── favicon.svg             знак XSatsu (две карточки крест-накрест)
├── css/studio.css          весь интерфейс; цвета — переменные в :root, в конце — компоненты 2-й версии
├── vendor/                 pdf-lib (создание PDF), fontkit (шрифты), pdf.js (показ PDF-шаблонов на экране)
├── fonts/                  встроенные шрифты с кириллицей (PT Sans/Serif/Sans Narrow, Montserrat, Marck Script, Bad Script, Lobster) + лицензии OFL
├── presets/assets/         картинки шаблонов: макет Дня социолога, «Первый иней», логотипы, 46 портретов и цитаты закладок
└── js/
    ├── core/               ЯДРО — без интерфейса, работает и в node (см. tests/)
    └── ui/                 ИНТЕРФЕЙС — панели редактора поверх ядра
```

### `app/js/core/` — ядро (всё в `window.XS`)

| Файл | Модуль | Отвечает за |
|---|---|---|
| `util.js` | `XS.*` | uid, clamp, debounce, data:URL ↔ байты, загрузка файлов (`fetchBytes` — с поддержкой `XS_EMBED`), диапазоны «1-5, 8» |
| `guest-data.js` | `GuestData` | Из v25: определение пола по ФИО/столбцу «Пол» (для `{Обращение}`) |
| `model.js` | `XS.Model` | Схема документа, типы элементов и их значения по умолчанию, `normalizeDoc` (защита от битых файлов), столбцы/записи/ассеты, форматы листов и бумаги |
| `fields.js` | `XS.Fields` | Подстановка `{Поле}` (без учёта регистра), встроенные поля `{№} {Проект} {Дата} {Обращение} {Сторона}`, **шаблон имени файла** (`fileName`, номер дополняется нулями) |
| `fonts.js` | `XS.Fonts` | Встроенные и загруженные шрифты; одни и те же байты → fontkit (переносы), FontFace (экран), pdf-lib (PDF) |
| `layout.js` | `XS.Layout` | Вёрстка текста: переносы, автоуменьшение до мин. размера, выравнивание, интерлиньяж, разрядка, выделение полей другим стилем, поиск отсутствующих в шрифте символов |
| `assets.js` | `XS.Assets` | Картинки и **PDF как шаблон**: размеры страниц (pdf-lib), растр для экрана (pdf.js), перекодирование WebP/SVG для PDF, вписывание (cover/contain/stretch) |
| `scene.js` | `XS.Scene` | Документ + запись + сторона → операции рисования; слои печати (цвет/текст, чёрный текст для лазера); пустые поля → линии/скрыть; предупреждения; выбор записей (все/текущая/отмеченные/диапазон, экземпляры) |
| `render-canvas.js` | `XS.CanvasRender` | Рисует сцену на canvas: предпросмотр, PNG/JPEG |
| `render-pdf.js` | `XS.PdfRender` | Рисует сцену в PDF: текст — текстом со встроенным шрифтом, PDF-фон — вектором (`embedPdf`), обрезка по карточке |
| `impose.js` | `XS.Impose` | Раскладка на листы (А4/А3/SRA3/по макету), поворот для плотности, метки реза, оборот при двусторонней печати (длинный/короткий край) |
| `zip.js` | `XS.Zip` | ZIP (STORE, UTF-8 имена), безопасные и уникальные имена файлов — перенесено из v25 |
| `export.js` | `XS.Export` | **Выгрузка**: `zip` (файл на запись: PDF/PNG/JPEG), `single` (один PDF), `sheets` (листы печати); имя архива; `check` — проверка всех записей |
| `store.js` | `XS.Store` | Проекты в IndexedDB браузера (`xsatsu-studio`: docs + meta с превью), файл проекта `.xsatsu.json` |
| `history.js` | `XS.History` | Отмена/повтор снимками (без ассетов) |
| `presets.js` | `XS.Presets` | Стартовые шаблоны: пригласительные, диплом классический, диплом «Первый иней», закладки (46 цитат, 2 стороны), открытка; `fromPdf` — проект из PDF-файла |
| `importers.js` | `XS.Import` | CSV/TSV/вставка из Excel, CSV-выгрузка таблицы, **импорт проектов v25** (`invite-studio`, `diploma-studio`, `bookmark-studio`) |

## Где искать, если…

- **Не тот текст в файле / не подставилось поле** → `fields.js` (`context`, `runs`).
- **Текст не помещается / переносы** → `layout.js`.
- **На экране и в PDF выглядит по-разному** → `render-canvas.js` vs `render-pdf.js` (обе рисуют одни операции из `scene.js`).
- **Имя файла / архива** → `fields.js#fileName`, `export.js#archiveName`, поле `output.naming` / `output.archive`.
- **Сколько на листе, метки, оборот** → `impose.js`.
- **Новый тип элемента** → `model.js` (ELEMENT_DEFAULTS) → `scene.js` → оба рендера → `inspector.js` → `layers.js` (иконка).
- **Новый шаблон** → `presets.js` (`LIST`), картинки — в `presets/assets/`.
- **Старый проект не открывается** → `importers.js#projectFromJson`.
- **Горячая клавиша / пункт контекстного меню** → `keys.js#MAP`, `context-menu.js`; само действие — в `selection.js`.
- **Выделение, группы, выравнивание** → `selection.js` (логика), `stage.js` (мышь), `layers.js` (дерево).
- **Иконка или цвет** → `icons.js`, переменные `:root` в `studio.css`; правила — `docs/ui-spec.md`.

## `legacy/v25/` — исходная версия (не менять)

Три отдельных редактора с собственным кодом отрисовки: `invitations.html`+`app.js` (canvas, растр),
`bookmarks.html`+`bookmark-render.js`, `diplomas.html`+`diploma-render.js` (pdf-lib), общий мастер печати
`print-center.js`, серверное хранилище пригласительных `api.php` (+ `invite-data/` на сервере). Студия заменяет
редакторы; мастер печати с профилями принтеров и серверная синхронизация в Студию пока не перенесены.
