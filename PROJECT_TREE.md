# Дерево проекта XSatsu

> Карта «где что лежит и за что отвечает». **Обновляйте этот файл в каждом изменении структуры** —
> новый файл, перенос функции, новый режим. Если описание и код расходятся — прав код, исправьте описание.

## Идея: одно ядро — много продуктов

Пригласительные, дипломы, закладки и открытки — это **один и тот же документ**:

```
Документ (xsatsu-doc)
├── page            размер макета, мм
├── sides[]         стороны: лицевая, оборот…
│   ├── background  фон: картинка ИЛИ страница PDF (остаётся вектором в выгрузке)
│   ├── elements[]  текст · изображение · фигура · линия · контур (координаты в мм); el.group — id группы
│   └── groups[]    группы слоёв {id, name, collapsed}; элементы группы всегда идут подряд (Model.cleanGroups)
├── data            таблица записей: столбцы (= поля {ФИО}, {Место}…) и строки (= люди / команды / цитаты)
├── greeting        правило для поля {Обращение} (Уважаемый / Уважаемая по полу)
├── assets          файлы проекта (картинки, PDF) в data:URL
├── fonts           загруженные шрифты (TTF/OTF)
└── output          настройки выгрузки: упаковка, формат, раскладка, шаблон имени файла
```

`kind` (Пригласительные / Дипломы / Закладки / Открытки / Свой) — только подпись и имя файла по умолчанию.
Любой шаблон умеет всё: PDF-фон, ZIP, листы печати, оборот, поля, линии для заполнения от руки.

Конвейер одинаковый для всех:
`документ + запись + сторона → XS.Scene.build() → список операций (мм) → экран/PNG (render-canvas) или векторный PDF (render-pdf)`.

## Корень репозитория

| Путь | Что это |
|---|---|
| `app/` | **Новая Студия.** Статический сайт без сборки: открыть `app/index.html` через любой веб-сервер. |
| `server/` | **Сервер** (PHP 8.3+/8.4, без фреймворка) + MariaDB: аккаунты, проекты, версии, доступ, файлы по SHA-256. См. раздел ниже и `docs/DEPLOY.md`. |
| `legacy/v25/` | Исходная версия v25 из архива, без изменений (для сравнения и отката). |
| `tests/core.test.cjs` | Проверка ядра без браузера: `node tests/core.test.cjs` (поля, имена файлов, таблицы, раскладка, все виды выгрузки, PDF-шаблон, мастер печати, лист совмещения). Файлы — в `tests/out/` (не в git). |
| `tests/api.test.cjs` | Проверка API: поднимает `php -S` с `tools/dev-router.php` на тестовой базе и проходит сценарии (установка, вход, CSRF, приглашения, файлы, проекты, конфликт 409, доступ, ссылка, версии, корзина, настройки, админка). |
| `tools/dev-router.php` | Локальный запуск Студии вместе с API: `php -S 127.0.0.1:8091 -t app tools/dev-router.php`. |
| `tools/deploy/server-install.sh` | Установка/обновление на сервере одной командой (база, config.php, миграции, обмен каталогов сайта, проверка). |
| `docs/DEPLOY.md` | Как устроено на o.utmns.ru, выкладка, первый вход, обслуживание, локальная разработка. |
| `tools/build-font-catalog.cjs` | Пересобирает `app/fonts/google-catalog.json` из npm-пакета `google-font-metadata` (команда — в начале файла). |
| `tools/extract-legacy-presets.cjs` | Достаёт картинки и цитаты из base64-скриптов v25 в `app/presets/assets/`. |
| `PROJECT_TREE.md` | Этот файл. |
| `README.md` | Что это, как запустить и развернуть. |
| `.github/workflows/ci.yml` | CI: на каждый PR — `node tests/core.test.cjs` (и проверки сервера, см. ниже). |
| `docs/ui-spec.md` | **Спецификация интерфейса:** пользователи и задачи, экраны, раскладка редактора, правила выделения и групп, полная таблица горячих клавиш, контекстное меню, айдентика (знак, цвета, иконки). Меняете интерфейс — сверяйтесь и обновляйте. |

## `app/` — Студия

```
app/
├── index.html              одна страница: главная (#/), редактор (#/doc/<id>), диалоги; порядок подключения скриптов
├── img/                    знак Студии: hero-portrait.webp (портрет в герое главной), logo-160.webp (шапка), favicon-32/64.png, apple-touch-icon.png, icon-192/512.png и icon-maskable-512.png (приложение)
├── manifest.webmanifest    v4: установка как приложение (PWA)
├── sw.js                   v4: service worker — Студия открывается без сети; API не кэшируется. Новая версия → новое имя CACHE
├── css/studio.css          весь интерфейс; цвета — переменные в :root, в конце — компоненты 2-й версии
├── css/motion.css          движение: вход экранов, окна, меню, уведомления, очередь карточек, «уменьшить движение»
├── css/brand.css           айдентика «Мундир» по логотипу: кант, эмблема-крест, золотая печать, блики; цвета — переменные из studio.css
├── css/mobile.css          телефон (≤820px: нижняя панель, листы-панели, окна снизу) и узкое окно (821–1180px)
├── vendor/                 pdf-lib, fontkit, pdf.js, fflate (ZIP/XLSX), petrovich (падежи), qrcode-generator — см. vendor/README.md
├── fonts/                  встроенные шрифты с кириллицей (PT Sans/Serif/Sans Narrow, Montserrat, Marck Script, Bad Script, Lobster, Tinos = «Times New Roman (Tinos)») + лицензии;
│                           google-catalog.json — каталог Google Fonts (~1900 семейств: категория, начертания, курсив, кириллица)
├── presets/assets/         картинки шаблонов: макет Дня социолога, «Первый иней», логотипы, 46 портретов и цитаты закладок
└── js/
    ├── core/               ЯДРО — без интерфейса, работает и в node (см. tests/)
    └── ui/                 ИНТЕРФЕЙС — панели редактора поверх ядра
```

## Где искать, если…

- **Не тот текст в файле / не подставилось поле** → `fields.js` (`context`, `runs`).
- **Текст не помещается / переносы** → `layout.js`.
- **На экране и в PDF выглядит по-разному** → `render-canvas.js` vs `render-pdf.js` (обе рисуют одни операции из `scene.js`).
- **Имя файла / архива** → `fields.js#fileName`, `export.js#archiveName`, поле `output.naming` / `output.archive`.
- **Сколько на листе, метки, оборот** → `impose.js`.
- **Проходы, порядок листов, поправки принтера** → `print-plan.js#build`; окно — `print-master.js`.
- **Новый тип элемента** → `model.js` (ELEMENT_DEFAULTS) → `scene.js` → оба рендера → `inspector.js` → `layers.js` (иконка). Пример — `qr`.
- **Падеж / форма имени не та** → `names.js` (`parse` — порядок слов, `apply`).
- **Проверка списка ругается не по делу** → `check.js#data`.
- **Не читается Excel** → `importers.js#readXlsx` / `readOds`.
- **Не сохраняется на сервер / конфликт** → `store.js#remote.save` (ревизия), `Projects.php#update`; окно — `account.js#conflict`.
- **Новый адрес API** → маршрут в `server/public/index.php`, обработчик в `server/src/*`, вызов через `XS.Api.call`, сценарий в `tests/api.test.cjs`.
- **Новая таблица** → новый файл `server/migrations/00N_….sql` (старые не менять).
- **Тёмная тема** → блок `[data-theme="dark"]` в конце `studio.css`; цвета только через переменные.
- **Поменять фирменные цвета или детали** → переменные `:root` в `studio.css` (`--accent`, `--gold`, `--crimson`…), детали — `brand.css`, `brand.js`; описание — `docs/ui-spec.md` §6.
- **Анимация дёргается или мешает** → `motion.css` (длительности `--dur-*`), `motion.js`; выключатель — настройка `motion`.
- **Импорт положил столбец не туда / создал лишний** → `import-map.js#guess` (синонимы `GROUPS`, `detectHeader`), окно — `import-dialog.js`.
- **Фото не разложились по записям** → `data-tools.js#matchPhotos`, окно — `photos.js`; размер и поворот — `assets.js#fromFile`.
- **Картинка по ссылке не рисуется / «Tainted canvas»** → `remote-images.js`, `scene.js#resolveImage`, сервер `RemoteImage.php`.
- **Подпись записи в списке не та** → `model.js#labelColumn` (ФИО по обращению/названию, а не первый столбец).
- **Таблица «Данные» (выделение, копирование, вставка)** → `sheet.js` (`parseTsv`, `paste`, `onKey`), стили `.data-table` в `studio.css`.
- **«Загружаем проект…» долго** → `api.js` (пределы ожидания), `store.js#hydrate`, `Assets.php#download`; заглушка недогруженного файла — `render-canvas.js#drawPicture`.
- **У пользователя старая версия** → `sw.js` (имя кэша, страница с `cache: no-cache`), `whats-new.js#registerWorker` (перезагрузка при обновлении), `?v=` в `index.html`.
- **На телефоне что-то не помещается** → `mobile.css` (≤820px — телефон, 821–1180px — узкое окно), листы — `mobile.js`.
- **Новый шаблон** → `presets.js` (`LIST`, флаг `isNew` — метка «новое»), картинки — в `presets/assets/`. Превью на главной рисуются сами (`home.js#thumbs`, кэш в localStorage — при изменении шаблонов увеличьте `VERSION`).
- **Поворот** → `el.rotate` (градусы, по часовой, вокруг центра; у линий всегда 0): `scene.js` (`op.rot/cx/cy`), `render-canvas.js`, `render-pdf.js#rotation`, ручка и размер повёрнутого — `stage.js`.
- **Новый формат поля** → `formats.js#apply` (+ подсказка в `HINTS`); слово по полу `{ФИО:принял/приняла}` и `{ФИО:буквы}` — `names.js`.
- **Команда в палитре** → `palette.js#commands` (или строка в `keys.js#MAP` — попадёт туда сама).
- **Шрифт: нет в списке / не скачивается / не тот в PDF** → каталог `app/fonts/google-catalog.json` (пересборка `tools/build-font-catalog.cjs`), скачивание `server/src/Fonts.php` (кэш `storage/font-cache`), выбор файла под начертание `fonts.js#pick`, окно `font-picker.js`.
- **Старый проект не открывается** → `importers.js#projectFromJson`.
- **Горячая клавиша / пункт контекстного меню** → `keys.js#MAP`, `context-menu.js`; само действие — в `selection.js`.
- **Выделение, группы, выравнивание** → `selection.js` (логика), `stage.js` (мышь), `layers.js` (дерево).
- **Иконка или цвет** → `icons.js`, переменные `:root` в `studio.css`; правила — `docs/ui-spec.md`.

## `server/` — сервер (PHP 8.4 + MariaDB)

```
server/
├── public/index.php     единая точка входа: таблица маршрутов /v1/… (в web-root — заглушка api/index.php из public/api-stub.php)
├── src/
│   ├── bootstrap.php    автозагрузка классов XSatsu\*, чтение config.php
│   ├── App.php          конфигурация (файл + переменные XS_*), PDO, помощники запросов, JSON-ответы, маршрутизатор, журнал (audit)
│   ├── Auth.php         сессии (cookie HttpOnly + CSRF-токен, проверка Origin), вход с ограничением попыток, первый админ по коду установки, регистрация по приглашению, смена пароля
│   ├── Projects.php     проекты: список (мои / доступные / корзина / все для админа), создание (сервер выдаёт id), сохранение с ревизией → 409, версии (раз в 10 мин и вручную, хранится 100), корзина, доступ людям и ссылкой
│   ├── Assets.php       файлы по SHA-256: какие отсутствуют, загрузка с проверкой хэша и типа по содержимому, выдача участникам проекта или по ссылке, очистка
│   ├── Settings.php     настройки сайта (регистрация, режим без входа, срок корзины, объявление) и пользователя (prefs, printers)
│   ├── Admin.php        пользователи, приглашения, журнал, статистика
│   ├── Fonts.php        шрифты Google Fonts целым TTF: берёт CSS у fonts.googleapis.com «как старый браузер», качает файл с fonts.gstatic.com, кэш storage/font-cache (до 400 МБ); без входа
│   ├── RemoteImage.php  картинка по ссылке (только после входа); защита от SSRF: http/https, порты 80/443, все IP имени публичные, соединение на проверенный IP (CURLOPT_RESOLVE), каждая переадресация проверяется, до 15 МБ, тип по сигнатуре
│   ├── Forms.php        v4: анкеты регистрации — поля из столбцов, публичная анкета без входа (ловушка для ботов, 30 ответов/час с адреса), ответы, «перенесено»
│   └── Migrate.php      миграции из migrations/*.sql, учёт в schema_migrations
├── migrations/001_init.sql   users, sessions, login_attempts, invites, projects, project_revisions, project_shares, assets, project_assets, settings, audit_log
├── migrations/002_forms.sql  v4: project_forms, form_responses
├── bin/                 migrate.php, create-admin.php, backup.php (mysqldump + файлы), cleanup.php (корзина, сессии, файлы)
└── config/config.example.php
```

API (`api/index.php?r=…`): `v1/health`, `v1/auth/{state,setup,login,logout,register,me}`, `v1/projects[/{id}[/restore|/revisions[/{rev}]|/shares[/{share}]]]`,
`v1/links/{код}`, `v1/projects/{id}/forms[/{form}[/responses|/ack]]`, `v1/f/{код}` (анкета гостя: GET — вопросы, POST — ответ), `v1/assets/{missing|{sha}}`, `v1/fonts/google` (`&family=&weight=&italic=`), `v1/images/fetch` (`&url=`), `v1/settings[/user|/system]`, `v1/admin/{users[/{id}],invites[/{id}],audit,stats}`.
