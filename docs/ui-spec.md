# Интерфейс XSatsu Студии: экраны, сценарии, клавиши

Документ — основа для интерфейса. Сначала задачи пользователя, потом экраны, которые их закрывают,
потом правила взаимодействия. Меняя интерфейс, сверяйтесь с ним и обновляйте его.

## 1. Для кого и зачем

Пользователь — организатор мероприятий кафедры (не дизайнер). Его задачи, по частоте:

1. **Сделать тираж по списку**: взять готовый макет (часто PDF от дизайнера), вставить список из Excel,
   получить по файлу на человека или листы для печати.
2. **Поправить макет**: передвинуть/выровнять текст, сменить шрифт, добавить логотип, подпись, линии.
3. **Проверить** перед печатью: все ли влезает, нет ли пустых и «битых» полей.
4. **Повторить через год**: открыть прошлый проект, заменить список и даты.

Отсюда принципы:
- **Одно ядро — один редактор.** Пригласительные, дипломы, закладки отличаются шаблоном, а не программой.
- **Макет в центре, данные рядом.** Всё, что влияет на результат, видно сразу на макете с реальной записью.
- **Привычно, как в Figma / Photoshop / Canva**: те же клавиши, выделение рамкой, Shift-клик, группы, контекстное меню.
- **Ничего не теряется**: автосохранение, отмена на 60 шагов, файл проекта, проверка перед выгрузкой.
- **Русская раскладка не мешает**: сочетания работают по физическим клавишам.

## 2. Экраны

| Экран | Когда | Что на нём |
|---|---|---|
| **Главная** | старт, список проектов | Логотип и короткое описание; «Создать»: из PDF-шаблона, готовые шаблоны (пригласительные, дипломы, закладки, открытка), пустой макет; «Открыть файл»; «Мои проекты» с превью, поиском, копией, скачиванием, удалением |
| **Редактор** | работа с проектом | Верхняя строка · слева «Слои» и «Данные» · в центре макет · справа «Свойства» · снизу строка состояния |
| **Выгрузка** (окно) | получить файлы | Что (все/текущая/отмеченные/диапазон), как (ZIP по файлу / один PDF / листы печати), формат, раскладка, слой печати, шаблон имени файла с предпросмотром |
| **Таблица** (окно) | правка списка целиком | Все записи и столбцы, переименование столбца = переименование поля везде, тип столбца (текст/картинка), экземпляры |
| **Вставка из Excel** (окно) | быстро добавить список | Поле вставки, предпросмотр, «заменить текущие» |
| **Проверка** (окно) | перед печатью | Список замечаний по записям, переход к записи |
| **Горячие клавиши** (окно, `?` / F1) | обучение | Все сочетания по группам — из той же таблицы, что и обработчик |

### Редактор подробно

```
┌ Верхняя строка: [лого→главная] Название · Тип ······ ↶ ↷ · Сохранено · Проект ▾ · ⌨ · Печать · [Выгрузить…] ┐
├ Слои | Данные ┬───────── макет ─────────┬ Свойства ───────────────┤
│ + Текст Поле  │ Стороны · ‹ запись › · масштаб │ один элемент: текст,  │
│ Картинка …    │                          │  шрифт, поля, положение, │
│ ▸ Группа      │      [страница]          │  выравнивание, печать    │
│   T ФИО       │                          │ несколько: выравнивание, │
│   ▣ Логотип   │                          │  распределение, общие    │
│               │                          │ ничего: макет, фон, PDF  │
├───────────────┴─ строка состояния: x/y курсора, выделено N, размер ─┴─────────────────────────┤
```

## 3. Выделение и слои

| Действие | Как |
|---|---|
| Выделить | клик по элементу на макете или в списке слоёв |
| Добавить/убрать из выделения | **Shift-клик** или **Ctrl-клик** (на макете и в списке) |
| Выделить рамкой | тянуть мышью по пустому месту макета (Shift — добавить к выделенному) |
| Выделить всё на стороне | **Ctrl+A** |
| Диапазон в списке слоёв | Shift-клик от выделенного до нужного |
| Элемент внутри группы | **двойной клик** по группе на макете или клик по слою в списке |
| Снять выделение | **Esc** или клик по пустому месту |

Группа — это папка в списке слоёв. Клик по любому её элементу на макете выделяет всю группу.
Группы двигаются, копируются, скрываются, закрепляются и удаляются целиком. Порядок слоёв в группе сохраняется.

Несколько выделенных элементов: двигаются вместе (мышью и стрелками), выравниваются относительно
общей рамки (или страницы, если выделен один элемент), распределяются равномерно (от трёх),
меняют общие свойства (непрозрачность, слой печати; у текстов — шрифт, размер, цвет, начертание).

### Шрифты

«Гарнитура» в свойствах текста — кнопка, на которой название набрано самим шрифтом. Она открывает окно «Шрифты»
(оно же — «Проект → Шрифты…» и палитра команд). Вкладки: **В проекте** (встроенные и добавленные; выбрать, убрать),
**Google Fonts** (поиск, категории, «только с кириллицей» — по умолчанию, превью на тексте выделенного элемента,
выбор насыщенности для «обычного»; жирный и курсивы подбираются сами), **С компьютера** (установленные шрифты, Chrome/Edge),
**Из файла** (TTF, OTF, WOFF, WOFF2; несколько файлов сразу, можно перетащить в окно). Выбор применяется сразу,
окно остаётся открытым, чтобы сравнить варианты; «Готово» закрывает. Добавленный шрифт хранится в проекте и встраивается в PDF.

## 4. Горячие клавиши

Обработчик и окно-справка читают одну таблицу (`app/js/ui/keys.js`). Сочетания определяются по физической
клавише (`event.code`), поэтому одинаково работают в русской и английской раскладке.
Ctrl на macOS — ⌘.

| Группа | Сочетание | Действие |
|---|---|---|
| Правка | Ctrl+Z / Ctrl+Shift+Z, Ctrl+Y | отменить / повторить |
| | Ctrl+C / Ctrl+X / Ctrl+V | копировать / вырезать / вставить (между сторонами и проектами) |
| | Ctrl+D | дублировать |
| | Delete, Backspace | удалить |
| Выделение | Ctrl+A | выделить всё |
| | Esc | снять выделение |
| | Tab / Shift+Tab | следующий / предыдущий элемент |
| Слои | Ctrl+G / Ctrl+Shift+G | сгруппировать / разгруппировать |
| | Ctrl+] / Ctrl+[ | выше / ниже |
| | Ctrl+Shift+] / Ctrl+Shift+[ | на передний / на задний план |
| | Ctrl+Shift+L | закрепить / открепить |
| | Ctrl+Shift+H | скрыть / показать |
| | F2 | переименовать слой |
| | Enter | редактировать текст |
| Положение | стрелки (Shift — ×10) | сдвиг на 0,5 мм (5 мм) |
| | Alt при перетаскивании | без привязки к направляющим |
| | Shift при перетаскивании | только по горизонтали или вертикали |
| Добавить | T / F / I / R / L / Q | текст / поле / картинку / фигуру / линию / QR-код |
| Вид | Ctrl+0 | вписать в окно |
| | Ctrl+1 | масштаб 100 % |
| | Ctrl+= / Ctrl+− , Ctrl+колёсико | масштаб |
| | Пробел + перетаскивание, средняя кнопка | двигать холст |
| Записи | PageDown / PageUp | следующая / предыдущая запись |
| Проект | Ctrl+S | сохранить (и напомнить про файл проекта) |
| | Ctrl+E | выгрузить… |
| | Ctrl+P | печать |
| | ? , F1 | горячие клавиши |
| v4 | Ctrl+K | палитра команд (везде, и на главной) |
| | Ctrl+H | найти и заменить |
| | B | добавить штрихкод |
| | Shift+R | повернуть выделенное на 90° |

Когда курсор в поле ввода, сочетания правки (Ctrl+Z, Ctrl+C…) работают для текста поля, а не для макета.

## 5. Контекстное меню (правая кнопка)

- На элементе или выделении: Копировать, Вырезать, Вставить, Дублировать · Сгруппировать / Разгруппировать ·
  На передний план, Выше, Ниже, На задний план · Закрепить, Скрыть · Удалить.
- На пустом месте: Вставить, Выделить всё, Добавить текст / поле.
- В списке слоёв — то же, что для элемента.

## 6. Айдентика

- **Имя**: XSatsu Студия. Знак — портрет с логотипа владельца (`app/img/`).
- **Айдентика «Мундир»** (`css/brand.css`, `js/ui/brand.js`) — всё взято с логотипа:
  - кобальт фона `#023bb9` — действие и выделение (`--accent`, в тёмной теме `#4a7dff`); градиент `--brand` — от тёмно-синего кителя к кобальту;
  - золото погон `#c99a45`/`#e7c27d` (`--gold`, `--gold-2`) — метка «новое», номера шагов, печать «Готово»;
  - красный кант воротника `#a82028` (`--crimson`) — тонкий кант «красный + золото» под шапкой редактора и по низу героя; направляющие — `--guide`;
  - чернила `#11172c` (текст, уведомления), сталь `#9ea4be` (полосы прокрутки), фон `#f3f5f9`;
  - **эмблема** — крест с фуражки (`XS.Icons.emblem`): водяной знак в герое (при наведении поворачивается на 45° и становится «X»), значок ожидания (поворачивается рывками, как печать), золотая печать в уведомлении «Готово» (`UI.toast(текст, false, {seal: true})`);
  - **портрет** с логотипа (`img/hero-portrait.webp`, из исходника владельца) — в карточке-герое на главной: выходит из кобальта справа, чуть следует за мышью, по козырьку пробегает блик; на телефоне — справа от текста. Он же — в пустом списке проектов (в золотом кольце) и в заголовке «Что нового»;
  - кант «красный + золото» — ещё и под заголовками окон;
  - редактор: стол с сеткой точек, лист с мягкой тенью, ручки рамки откликаются на наведение (ручка поворота — золотом), у разделов свойств — риска канта, выравнивание текста — значками, активный слой и выбранный вариант в окнах — полоской кобальта слева;
  - движение: блик по знаку при наведении, блик по главной кнопке, кант «прорисовывается» при входе; пасхалка — пять щелчков по знаку на главной. Всё выключается «Настройки → Анимации» и системным «уменьшить движение».
- **Иконки**: единый набор линейных SVG 16–18 px, толщина 1.75, без эмодзи.
- **Тон текстов**: коротко, по-русски, глаголом («Выгрузить», «Вставить из Excel»), с подсказками у сложных мест.
- **Пустые состояния** объясняют следующий шаг.
- **Темы**: светлая, тёмная и «как в системе» (кнопка луна/солнце на главной, «Настройки → Личные»).
  Все цвета — только переменные `:root`; тёмная тема переопределяет их в `[data-theme="dark"]` и `prefers-color-scheme`.
  Макет (бумага) всегда белый.

## 7. Версия 3: новое в интерфейсе

- **Настройки** (шестерёнка на главной и в редакторе): вкладки «Личные», после входа — «Аккаунт», для админа — «Сайт» и «Пользователи».
- **Поля с формой**: под «Вставить поле» — строка «Падеж / форма»: поле + форма → `{ФИО:дат}`, `{ФИО:инициалы}`, `{Место:верх}`.
- **QR-код** — элемент слоя (кнопка «QR», клавиша Q): данные из поля (`{Ссылка}`), надёжность L/M/Q/H, подложка.
- **Показывать, если** — у любого элемента: поле + условие (заполнено / пусто / равно / не равно / содержит).
- **Проверка** («Проект → Проверить все записи»): сначала замечания по данным (повторы, пустые поля, латиница в русских словах,
  лишние пробелы, пол), затем по макету; кнопки автоисправления пробелов и латиницы. Окно выгрузки предупреждает о замечаниях.
- **Импорт таблиц**: кнопка «Файл» принимает XLSX, ODS и CSV (UTF-8 или Windows-1251); дальше — окно сопоставления столбцов (§11a).

### Мастер печати

«Проект → Мастер печати…», Ctrl+Shift+P или ссылка в окне выгрузки (листы для печати).

- **Вкладка «Тираж и проходы»**: режим (одна сторона / автоматический дуплекс / ручной переворот / два принтера: струйный цвет
  и лазерный текст), принтер или пара принтеров, диапазон листов, «Повторить набор», размер пакета (по умолчанию 100 листов в PDF).
  Ниже — список проходов по порядку: что печатать, каким принтером, подсказка (как перевернуть стопку, дать чернилам высохнуть),
  кнопки «Печатать» (PDF в новой вкладке), «PDF» и «Проход напечатан». Следующий проход подсвечен; отметки хранятся в браузере
  и сбрасываются, если поменялись данные или тираж.
- **Вкладка «Принтеры»**: профили (название, назначение, поправки X/Y лица и оборота, край переворота, обратный порядок оборотов,
  как класть бумагу). После входа профили хранятся в аккаунте. «Лист совмещения» — PDF на два стороны с линейкой 50 мм,
  крестами, «ВЕРХ ЛИЦА» и цветной полосой в рамке (для проверки двух принтеров) — печатается с поправками профиля.
- Раскладка и бумага берутся из окна выгрузки; сдвиги из окна выгрузки складываются с поправками профиля.

## 8. Версия 4: новое в интерфейсе

- **Палитра команд** — Ctrl+K или кнопка «Команды» (на главной и в редакторе). Ищет по словам: действия (из той же таблицы, что и клавиши),
  пункты меню «Проект», инструменты списка, шаблоны («бейдж» → новый проект), стороны, слои и записи (по любому значению).
  ↑/↓ — выбор, Enter — выполнить, Esc — закрыть. Пустой запрос показывает основные действия.
- **Поворот**: круглая ручка над рамкой выделенного элемента (без Shift — прилипает к 0/90/180/270°, с Shift — шаг 15°),
  поле «Поворот, °» и кнопки ⟲ 90° / ⟳ 90° / 0° в «Положении», Shift+R. Рамка и ручки поворачиваются вместе с элементом;
  размер повёрнутого меняется в его собственных осях, противоположный край остаётся на месте. Линии не поворачиваются (их задают концы).
- **Штрихкод** (кнопка «Код», клавиша B): Code 128 или EAN-13, данные из полей (`{№:000000}`, `{Номер билета}`), подпись цифрами, подложка.
  Предупреждение, если модуль уже 0,19 мм.
- **Форматы полей** — в конструкторе «Падеж / форма» добавлены даты, «прописью», «римское», «порядковое», «000», слово по полу.
- **Шаблоны**: карточки с живым превью; новые помечены «новое».
- **Инструменты** (кнопка в «Данных», Ctrl+H): вкладки «Найти и заменить» (в таблице и/или макете, регистр, слово целиком, счётчик найденного),
  «Порядок и повторы», «Фото» (много файлов → по записям; отчёт о неразложенных), «Google Таблица» (ссылка запоминается в проекте).
- **Анкета регистрации** («Проект → Анкета регистрации…», только для проектов в аккаунте): галочки у столбцов, тип поля
  (строка, абзац, почта, телефон, выбор, дата), обязательность, предел ответов и срок. У каждой анкеты — ссылка, QR, счётчики
  «ответов / новых», кнопки «Забрать ответы», «Закрыть приём», «Удалить». При открытии проекта с новыми ответами — подсказка.
  Страница гостя `#/form/<код>` — без редактора и без входа, крупные поля, сообщение «Спасибо», ловушка для ботов.
- **Без сети**: после первого открытия Студия запускается из кэша (service worker); внизу — плашка «без сети».
- **Что нового**: окно один раз после обновления; снова — звёздочка на главной или Ctrl+K → «Что нового».

## 9. Плавность и телефон (v4.1)

- **Движение**: короткие анимации 120–280 мс, только прозрачность и сдвиг. Главная появляется с очередью карточек, редактор —
  панели выезжают с краёв, макет проявляется; окна открываются и закрываются с анимацией (на телефоне — выезжают снизу);
  меню и контекстное меню «раскрываются»; уведомления всплывают снизу и уходят; смена записи или стороны — мягкая смена страницы;
  переключение темы — плавная смена цветов; пока список проектов идёт с сервера — заглушки-карточки.
- **Выключатель**: «Настройки → Анимации» — как в системе / включены / выключены. «Как в системе» уважает «уменьшить движение».
- **Телефон (до 820 px)**: сверху одна строка — назад, название, отмена/повтор, значок сохранения, «⋯» (команды, печать, настройки,
  аккаунт и всё меню «Проект»), «Выгрузить» значком. Макет — на весь экран, вписывается сам при повороте. Снизу — панель
  «Слои / Данные / Свойства / Выгрузить»; панели выезжают листом на две трети экрана, закрываются повторным нажатием,
  смахиванием вниз за ручку или нажатием на макет. Точка на «Свойствах» — есть выделенный элемент.
- **Главная на телефоне**: шапка значками, шаблоны и проекты в две колонки.
- **Узкое окно (821–1180 px)**: панели уже, в верхней строке — только значки там, где есть подсказка.
- Видимая рамка фокуса с клавиатуры у всех нажимаемых элементов.

## 10. Надёжность и выверка вёрстки (v4.2)

- **Открытие проекта с сервера** больше не может «висеть»: у каждого запроса есть предел ожидания (45 с, файлы — 3 мин),
  в окне ожидания виден ход — «Загружаем файлы проекта: 2 из 5…». Если файл (фон, картинка, шрифт) не пришёл, проект всё равно
  открывается: на месте файла — пунктирная заглушка «…не загрузился», внизу — уведомление с причиной; на сервере файл не трогается.
  Сервер отдаёт файлы без сжатия и буферов PHP (из-за них ответ мог не заканчиваться).
- **Обновление Студии**: страница всегда сверяется с сервером, новая версия ищется сразу (`updateViaCache: none`);
  если она пришла, пока Студия открыта, — на главной страница тихо перезагружается, в редакторе — подсказка «обновите страницу».
- **Карточка проекта**: все кнопки в одну строку; на узкой карточке «Открыть» становится значком.
- **Переключатели со словами** («как есть / линии / скрыть», «растянуть / заполнить / целиком») — под подписью на всю ширину,
  без переноса кнопок. Длинные подписи полей переносятся по слогам.
- **Вписывание макета** учитывает настоящие поля области и пересчитывается при любом изменении её размера (панели, листы, поворот).
- **Телефон и планшет**: кнопки «Текст/Поле/…» в листе «Слои» — сеткой; вкладки окон («Настройки», «Мастер печати») — в одну строку
  с прокруткой; на планшете в портрете листы не шире 640 px, по центру.
- Проверено на ширинах 360, 390, 414, 600, 768, 900, 1024, 1180, 1280, 1440, 1920 (светлая и тёмная тема): без горизонтальной прокрутки.

## 11. Таблица записей как в Excel (v4.3)

Окно «Данные → Таблица» (`ui/sheet.js`):
- **Выделение**: протяжка мышью, Shift+клик, Shift+стрелки; клик по номеру строки — строка целиком, по заголовку столбца — столбец,
  по углу или Ctrl+A — всё. Активная ячейка — рамка, диапазон — подсветка с контуром, номера строк и заголовки подсвечиваются.
- **Ввод**: начните печатать — значение ячейки заменяется; F2, Enter или двойной клик — правка с сохранением текста;
  Enter / Tab — следующая ячейка, Esc — отмена правки. На телефоне: касание выделяет, повторное касание — правка.
- **Буфер обмена** — системный, формат Excel / Google Таблиц (табуляция, кавычки, переносы внутри ячеек): Ctrl+C, Ctrl+X, Ctrl+V.
  Вставка блока добавляет недостающие записи и столбцы («Столбец N»); одно значение в выделенный диапазон заполняет весь диапазон.
- **Delete / Backspace** очищают выделение; Ctrl+Z / Ctrl+Y — отмена и повтор.
- Внизу таблицы — пустая строка «новая запись»: начните печатать или вставьте — запись появится.
- «Удалить строки» — удаляет отмеченные галочками или (если галочек нет) строки выделения. Столбец «Экз.» — число экземпляров.
- Строка состояния: «Запись 2 · {Роль}» или «Выделено ячеек: 6 (3 × 2)», подсказка по клавишам.
- **Перестановка столбцов** (v4.8): ручка ⋮ в заголовке — перетащить (синяя полоса показывает место), или Ctrl+Shift+← / →.
  Подпись записи в списке и навигации берётся из столбца ФИО (`Model.labelColumn`), а не из первого — перестановка её не меняет.
- **Вставка со строкой заголовков** («ФИО, Email…» сверху) открывает окно импорта, а не пишет заголовки в записи.

## 11a. Импорт и фото пачкой (v4.8)

- **Окно «Импорт списка»** (`ui/import-dialog.js`) — для «Файл», «Из Excel», «Импорт» в таблице и Google Таблицы. Для каждого
  столбца файла: название, вид данных (ФИО, почта, пол, фото, ссылки), примеры → куда класть (столбец проекта / новый / «Экз.» / не загружать)
  и почему так угадано (по названию, по данным, те же значения, как в прошлый раз). Флажок «Первая строка — названия столбцов»
  (снят сам, если первая строка — тоже данные, например просто список ФИО). Режимы: добавить; обновить совпадающие по ключу, новых добавить;
  вписать по порядку в текущие записи; заменить. Итог одной строкой («добавится 2 · обновится 1 · повторов пропущено 1»), предпросмотр.
- **Окно «Фото для записей»** (`ui/photos.js`): кнопка «Фото» в «Данных», «Фото пачкой» в таблице или перетаскивание файлов на таблицу.
  Файлы и ZIP; список «миниатюра — файл — запись» с причиной совпадения; запись можно сменить вручную; на одну запись — одно фото;
  «заменять уже выбранные» — флажок. Фото уменьшаются до 1600 px по длинной стороне.
- **Картинка по ссылке**: в форме записи кнопка «Ссылка…»; ссылка в ячейке столбца-картинки скачивается в проект в фоне,
  в таблице показывается миниатюрой, ошибка — красным с причиной. Без копии на макете — пунктирная заглушка, выгрузка сначала докачивает.

Окна «Инструменты» и «Настройки»: вкладки — отдельной строкой под заголовком, не наезжают на кнопку «Закрыть».
